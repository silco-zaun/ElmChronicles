## Stylized Rendering (툰 셰이딩·외곽선)

> 개발 일정(1~4주차)에는 포함하지 않으며, 일정 완료 후 여유가 있을 때 진행한다.
> 

- 목표: 블록형 로우폴리(KayKit) 모델은 그대로 두고 렌더링만 바꿔 동화풍 분위기를 강화한다.
- Stylized Rendering: 포토리얼 대신 의도한 화풍을 화면 전체에 일관되게 표현하는 렌더링. NPR(Non-Photorealistic Rendering)이라고도 한다.

---

## 1. 두 갈래

| 구분 | 방식 | 참고 게임 |
| --- | --- | --- |
| Stylized PBR | 라이팅은 물리 기반 그대로, 형태·텍스처·색만 과장. 엔진 기본 기능으로 가능 | Fortnite, Sea of Thieves, 드래곤 퀘스트 11 |
| NPR | 빛 계산 결과 자체를 의도적으로 왜곡(셀 셰이딩, 외곽선 등) | 길티기어 Xrd, Hi-Fi Rush, 원신, 젤다 야숨 |

---

## 2. 핵심 기법

| 분류 | 기법 |
| --- | --- |
| 셰이딩 | N·L을 step·램프 텍스처로 2~3단계 양자화 / 그림자는 검정 대신 색조 이동(따뜻한 색 → 보라·파랑) / 림 라이트 / 경계가 딱 떨어지는 하이라이트 |
| 외곽선 | 인버티드 헐 / 포스트프로세스 엣지 검출(Depth·Normal에 Sobel) / 텍스처 내부선 |
| 색·텍스처 | 핸드페인트 / 팔레트 아틀라스(KayKit 방식) / 버텍스 컬러 |
| 얼굴 그림자 | 노멀 수동 편집(길티기어 Xrd) / SDF 그림자 맵(원신) |
| 애니메이션 | 프레임을 건너뛰는 limited·stepped 애니메이션 |

### 외곽선 방식 비교

| 방식 | 원리 | 장단점 |
| --- | --- | --- |
| 인버티드 헐 | 메시를 노멀 방향으로 부풀려 뒷면만 렌더링 | 굵기 제어 쉬움, 오브젝트별 적용 가능 / 각진 모델은 모서리에서 선이 끊길 수 있음 |
| 포스트프로세스 엣지 검출 | Depth·Normal 버퍼에 Sobel 필터 | 화면 전체 일괄 적용 / 거리에 따라 굵기가 들쭉날쭉할 수 있음 |
| 텍스처 내부선 | 텍스처에 선을 직접 그림 | 주름·디테일 선에 적합 |

---

## 3. UE 구현 방식

> UE는 디퍼드 렌더러라서 머티리얼 그래프에서 라이팅 결과를 직접 받아 가공할 수 없다.
> 

| 방법 | 방식 | 장점 | 단점 |
| --- | --- | --- | --- |
| 포스트프로세스 툰 | `PostProcessInput0` ÷ `BaseColor`로 라이팅 양 추출 → 단계로 끊은 뒤 다시 곱함 | 엔진 수정 없이 씬 전체에 적용 | 반투명·이미시브 처리가 까다로움, 오브젝트별 제어는 Custom Stencil 필요 |
| Unlit + 커스텀 라이팅 | 라이트 방향을 Material Parameter Collection으로 넘겨 직접 계산 | 완전한 제어 가능 | 그림자 받기·다중 라이트를 직접 구현해야 함 |
| 엔진 소스 수정 | 커스텀 Shading Model 추가 | 가장 정석, 품질 최고 | 소스 빌드 엔진 필요, 엔진 버전 업 때마다 머지 |

- 인버티드 헐 외곽선: 메시 컴포넌트의 Overlay Material(UE 5.1+) 슬롯 사용. 머티리얼을 Masked + Two Sided로 설정 → WPO로 노멀 방향 팽창 → `TwoSidedSign`으로 앞면 마스킹
- 포스트프로세스 외곽선: SceneDepth·WorldNormal에 Sobel 적용, Custom Depth Stencil로 대상 제한

### 함께 조정할 설정

| 항목 | 조정 | 이유 |
| --- | --- | --- |
| Auto Exposure | Manual로 고정 | 화면 밝기에 따라 팔레트가 흔들리지 않게 |
| 톤매퍼 | 툰 포스트프로세스의 Blendable Location을 톤매핑 이전에 배치, 또는 색 보정 | Filmic 톤매퍼가 채도·색을 바꿈 |
| Lumen | 강도를 낮추거나 끔 | GI가 평평한 셀 톤을 뭉갬 |
| 그림자 | 라이트 Source Angle 축소 | 부드러운 그림자 경계가 툰 단계 경계를 흐림 |
| 기타 포스트프로세스 | Motion Blur·Chromatic Aberration 끄기, Bloom 약하게 | 스타일 일관성 |

---

## 4. 적용 계획

1. 포스트프로세스 머티리얼로 2~3단계 셀 셰이딩 + 색 있는 그림자
2. 외곽선은 캐릭터·몬스터에만 Overlay Material(인버티드 헐)로 적용
3. Manual Exposure로 노출 고정 + 컬러 그레이딩
4. 레벨 하나에만 먼저 샘플 적용 → 전후 스크린샷 비교 후 전체 적용 여부 결정
