## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 싱글플레이 액션 RPG |
| 참고 게임 | 젤다 야숨, 위처3, 엘더스크롤5, 원신(스킬 조작) |
| 시대 배경 | 중세 유럽 |
| 시작 장소 | 엘름 왕국 |
| 사망 시 | 마을 병원에서 다시 시작 (HP·MP가 가득 찬 채로, 사망 페널티 없음) |
| 적용 기술 | AssetManager, GameAbilitySystem(GAS), AIPerception + Behavior Tree |

## 5. 능력치 및 전투 공식

### 5.1 능력치 정의 (플레이어·몬스터 공통)

| 능력치 | 데이터명 | 설명 |
| --- | --- | --- |
| 레벨 | Level | 공격력 ~ 마나를 정한다 (6.1, 7.2) |
| 공격력 | PhysicalAttack | |
| 마법 공격력 | MagicalAttack | |
| 방어력 | PhysicalDefense | |
| 마법 방어력 | MagicalDefense | |
| 체력 | HP | 최대치는 MaxHP |
| 마나 | MP | 최대치는 MaxMP |
| 이동 속도 | MoveSpeed | 캐릭터마다 정한다. 플레이어 500, 몬스터·NPC 300 (cm/초) |
| 공격 속도 | AttackSpeed | 공격 동작의 속도 배율. 1.0이 원래 속도 |
| 공격 사거리 | AttackRange | 근접 50, 원거리 500 (cm, 몸 표면 사이 거리) |
| 감지 거리 | DetectRange | 몬스터·NPC만. 적을 알아채는 거리 800 (cm) |

### 5.2 데미지 공식

```
데미지 = 공격력 × 배율 × 100 / (100 + 방어력)   (최소 1)
```

- 물리 공격은 공격력 / 방어력, 마법 공격은 마법 공격력 / 마법 방어력으로 계산한다.
- 배율: 일반 공격 100%, 스킬은 6.2 표의 효과.
- 공격력은 공격을 시작한 순간(투사체는 쏜 순간), 방어력은 맞는 순간의 값을 쓴다.

### 6.2 스킬

> 원신처럼 E는 기본 스킬, Q는 필살기다. 둘 다 처음(Lv1)부터 쓸 수 있다. (2026-10-30 변경: 숫자키 1 ~ 4의 스킬 4개 → E / Q 두 개)

| 키 | 스킬명 | 유형 | 효과 | MP | 쿨타임 |
| --- | --- | --- | --- | --- | --- |
| E | 회전베기 | 물리 / 주변 360° | 바바리안 휠윈드처럼 돌면서 주변(반경 2.5m)의 적을 모두 벤다. E를 누르고 있는 동안 계속 돌고, 도는 중에도 움직일 수 있다. 0.5초마다 공격력 × 50% | 시작 10, 도는 동안 초당 10 | 3초 (회전이 끝난 뒤부터) |
| Q | 회오리 바람 | 마법 / 넓은 범위 | 주변 넓은 반경(6m)에 회오리바람을 일으켜 한 번에 큰 피해를 준다. 마법 공격력 × 500% | 100 | 30초 |

- 회전베기는 E를 떼거나 MP가 모자라면 멈춘다.
- 회오리 바람이 마법인 이유: 다른 마법 스킬이 없어져서, 물리로 하면 마법 공격력과 사자의 목걸이(마법 공격력 +100)를 쓸 곳이 없다.
- 반경, 배율, MP, 쿨타임은 이전 스킬(회오리 베기 50MP 12초, 낙뢰 100MP 30초)을 바탕으로 정한 임시 수치다. 플레이해 보고 조정한다.
