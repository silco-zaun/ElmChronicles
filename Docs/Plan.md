## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 싱글플레이 액션 RPG |
| 참고 게임 | 젤다 야숨, 위처3, 엘더스크롤5 |
| 시대 배경 | 중세 유럽 |

## 4. 월드

### 4.1 맵 구조

- 참고: 바람의나라, 크로스게이트
- 가운데에 마을이나 왕궁이 있고, 동서남북에 바깥세상이 있다.
- 마을: 아이템, 병원, 상점 등의 시설
- 바깥세상: 몬스터 출현

### 4.2 왕국 설정

#### 👑 인간의 숲 왕국 (따뜻하고 평화로운 동화 느낌)

| 왕국 | 설명 |
| --- | --- |
| 엘름 (Elm) | 커다란 느릅나무 아래, 인간과 동물들이 옹기종기 모여 사는 평화로운 농경 왕국 |
| 멜로 (Mello) | 따뜻하고 부드러운 햇살이 내리쬐는, 과수원이 풍요로운 숲속 인간 마을 |
| 우드 (Wood) | 나무로 지은 아기자기한 성과 집들이 모여 있는 가장 직관적이고 친근한 왕국 |

#### 🧝 엘프의 숲 왕국 (신비롭고 맑은 느낌)

| 왕국 | 설명 |
| --- | --- |
| 리안 (Rian) | 이슬과 시냇물을 닮아 맑고 깨끗한 마법의 숲 왕국 |
| 리프 (Leaf) | 푸른 나뭇잎과 세계수가 끝없이 펼쳐진 정통 엘프의 거처 |
| 플로라 (Flora) | 사계절 내내 지지 않는 신비한 꽃들이 가득한 아름다운 요정 왕국 |

#### 🐗 오크의 숲 왕국 (거칠지만 자연 친화적인 느낌)

| 왕국 | 설명 |
| --- | --- |
| 모스 (Moss) | 깊고 어두운 이끼 숲속에 자리 잡은, 자연의 날것 그대로를 보존한 오크 부족의 영토 |
| 루트 (Root) | 땅속 깊이 박힌 거대한 나무뿌리 주변에 세워진 투박하고 단단한 요새 왕국 |
| 바크 (Bark) | 단단한 나무껍질처럼 거칠고 강인한 오크 전사들이 자연을 지키며 사는 곳 |

## 5. 능력치 및 전투 공식

### 5.1 능력치 정의 (플레이어·몬스터 공통)

| 능력치 | 데이터명 |
| --- | --- |
| 공격력 | PhysicalAttack |
| 마법 공격력 | MagicalAttack |
| 방어력 | PhysicalDefense |
| 마법 방어력 | MagicalDefense |
| 체력 | HP |
| 마나 | MP |

### 5.2 데미지 공식

```
데미지 = 공격력 × 100 / (100 + 방어력)
```

## 9. 스토리 및 퀘스트

### 퀘스트 1

> 오늘은 자랑스러운 엘름 왕국의 왕실 기사직을 내려놓고 은퇴하는 날이다. 왕궁으로 가서 하몬 왕에게 작별 인사를 건네고 왕의 하사품을 받자.
> 

| 장소 | 완료 조건 | 보상 |
| --- | --- | --- |
| 왕궁 | 하몬 왕에게 작별 인사 | 5000골드 |

### 퀘스트 2

> 왕에게 받은 골드로 상점에 가서 무기와 방어구를 구매하자.
> 

| 장소 | 완료 조건 | 보상 |
| --- | --- | --- |
| 상점 | 구매한 무기와 방어구 착용 | - |

### 퀘스트 3

> 왕실 기사에서 은퇴했으니 생계를 이어나가기 위해 퀘스트를 진행해야 한다. 선술집에 가서 퀘스트가 있는지 확인하자. 왕국 근처의 고블린 무리를 잡아달라는 퀘스트가 있었다.
> 

| 장소 | 완료 조건 | 보상 |
| --- | --- | --- |
| 선술집 → 왕국 근처 | 고블린(노멀) 무리 처치 | 1000골드, 체력 포션 10개, 마나 포션 10개 |

### 퀘스트 4

> 동쪽 동굴에 전설의 무기가 있다는 소문을 들었다. 동쪽 동굴로 가보자.
> 

| 장소 | 완료 조건 | 보상 |
| --- | --- | --- |
| 동쪽 동굴 | 오크(에픽) 2마리 처치 | 사자의 검, 사자의 갑옷 (오크 드랍) |

### 퀘스트 5

> 왕에게 편지가 도착했다. 빠르게 왕궁으로 오라는 명령이다. 왕궁으로 가자.
악당 보이드 레인에게 공주가 납치됐다는 소식이다. 보이드 레인은 공주가 가진 신비한 힘을 손에 넣고 싶어 했다.
엘름 왕국 남쪽으로 계속 가다 보면 보이드 레인이 살고 있는 그림자 요새가 있다.
> 

| 장소 | 완료 조건 | 보상 |
| --- | --- | --- |
| 왕궁 → 그림자 요새 | 보이드 레인(보스) 처치 | 10000골드, 사자의 목걸이 (보이드 레인 드랍) |
